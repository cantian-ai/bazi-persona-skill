# 八字人格 Bazi Persona Skill

**一個生日，一個活的人格。**

基於八字命理，生成會聊天、有情緒、會隨時間變化的 AI 人格。

[![npm](https://img.shields.io/npm/v/bazi-persona-skill)](https://www.npmjs.com/package/bazi-persona-skill)

**參天AI / Cantian AI** &nbsp; · &nbsp; Claude Code &nbsp; · &nbsp; OpenClaw &nbsp; · &nbsp; 45+ Agent 平台

- **一個生日就能建立** — 給個名字和出生日期，幾秒鐘生成完整人格，不用懂八字
- **不是算命，是活的人格** — 會聊天、有脾氣、會隨大運/流年/流月/流日/流時變化
- **作弊模式** — 一句話切換深度剖析，從八字的靜態和動態角度拆解狀態、決策、趨勢
- **越聊越真** — 每一條真實資訊都會讓人格更準確，不是固定模板
- **說人話就能用** — 不用學指令，自然語言對話搞定一切
- **純本地運行** — 不連網、不上傳，所有資料留在你的電腦上

```
👤  幫我建立八字人格：小A，女，96年8月12日下午3點半，上海人，我同事

🤖  排盤完成 ✓

    【人格簡況】
    1. 一句話總結：表面隨和實際主意很正，做事先算清楚再出手
    2. 說話感覺：不廢話但也不冷，會照顧人但不會慣著人
    3. 做決定看重：可持續性和風險收益比
    4. 壓力下變化：更強調底線和交付，溝通變簡潔
    5. 最近狀態：穩中提效，有意識地收斂社交

    MBTI 映射：INTJ（八字推導）
    · I → 日主丙火坐申金，能量內收不外放
    · N → 食傷生財鏈完整，直覺驅動決策
    · T → 偏官+偏印組合，邏輯優先於感受
    · J → 年柱己卯正印，安全感來自計劃和掌控

    已進入 [小A] 對話模式 ✓
    下一句話開始，我就是她。
```

### 和人格聊天 — 不是在「扮演」，是真的像那個人

建立完成後，AI 就是這個人。同樣的問題，不同八字的人格回應完全不同：

**內向型人格（丙火日主，官殺旺，內斂沉穩）：**

```
👤  你最近是不是心情不太好？

🤖  沒有啊……就是最近事比較多。
    怎麼了？
```

```
👤  感覺你最近都不怎麼說話

🤖  嗯，確實。最近腦子一直在想事情，沒太顧上聊天。
    不是不想理你，就是暫時沒什麼想說的。
    過兩天就好了。
```

**外向型人格（甲木日主，食傷旺，表達慾強）：**

```
👤  你最近是不是心情不太好？

🤖  啊被你看出來了？？
    煩死了最近，工作上一堆破事，我跟你說——
    那個新來的組長真的離譜，開會開了兩小時全是廢話。
    我都想當場翻白眼了。
    你中午有空嗎，出來吃飯我跟你好好吐槽一下。
```

```
👤  哈哈好，中午出來

🤖  走走走，我知道一家新開的湘菜館，
    上次路過看著還不錯，正好今天試試。
    你幫我拍照啊我要發朋友圈。
```

> 不是 AI 在背台詞。是八字推導出的決策模式、情緒節奏、表達習慣在驅動每一句回應。
> 同一個問題，不同八字的人格會給出完全不同的答案。

### 作弊模式 — 從八字與流年深度剖析一個人

普通聊天裡，AI 就是那個人，不會「出戲」。
但你隨時可以說「打開作弊模式」，對話就從閒聊切換到深度剖析——
人格會從八字和流年角度拆解自己，像一份即時更新的人生說明書：

```
👤  打開作弊模式

🤖  作弊模式已開啟 🔓
    現在可以從八字和流年角度深度提問。
    隨時說「關閉作弊模式」回到正常聊天。
```

```
👤  你今天開心嗎？

🤖  【今日狀態 · 庚午日】
    說實話，今天不算開心，但也不是不開心——是躁。

    午火是我的劫財 → 我今天行動力很足，但容易衝動。
    庚金壓在我天干 → 會有人管我、給我框架，我會覺得煩但別硬頂。
    今日神煞帶桃花 → 我社交狀態不錯，但災煞同現，容易在情緒上頭時答應不該答應的事。

    身體上我是丙火日主，今天遇午火心火偏旺，下午會煩躁、坐不住。
    💡 你要找我聊事情上午來，下午我大概率沒耐心。想約我出去可以，但別讓我當場做決定。
```

```
👤  我們在一起合適嗎？

🤖  【合盤分析】
    從盤面看，有緣分，但有一個不對稱的地方要說清楚。

    強信號：你的妻星命中我
    丁火男，妻星是壬水和癸水。我日主正好是癸水——
    我直接落在你的妻星位置上。這個命中不弱。

    弱信號：我的夫星不直接命中你
    癸水女，夫星是戊土和己土。你是丁火，不在我的夫星範圍裡。
    從我這邊看，你不是我命盤裡「一眼就認定」的類型，
    需要更多主動確認，不會「自然就覺得你是那個人」。

    時間窗口重疊
    你的婚配窗口：2028–2029。我的婚配窗口：2027–2028。
    2028 年是重疊點。

    💡 所以情況是這樣的：
    你命盤裡認定了我，但我命盤裡沒有直接認定你。
    這意味著你會比我更確定，而我需要更多時間和相處才能確認。
    2028 年是唯一的窗口重疊——如果要推進，那一年最關鍵。

    我知道你在問這個問題，但你有沒有當面跟我聊過？
```

```
👤  現在去找你匯報合適嗎？

🤖  【當前溝通窗口】
    今天庚午日，庚金是我的偏財 → 我今天對「結果」和「效率」敏感，
    不想聽過程，只想聽結論。

    午火是劫財 → 下午我的耐心會比上午差很多，
    容易急躁，你說到一半我可能就打斷你。

    💡 建議：
    上午找我，開口先說結論，再補一句「需要展開說嗎」。
    如果是壞消息，別鋪墊，直接講，我反而更能接住。
    下午三點以後別來，那會兒我大概率在煩別的事。
```

> 作弊模式下直接對人格提問，獲得八字和流年角度的深度自我剖析。
> 關掉就回到正常聊天，兩種模式互不干擾。

### 越聊越真 — 餵給她真實資訊，人格會自己進化

人格不是建立完就固定了。你可以隨時補充真實資訊，人格會自動吸收並聯動八字重新解讀：

```
👤  小A最近升職了，當上了小組長

🤖  已更新 ✓ 記錄了「近期升職為小組長」。

    聯動分析：丙火日主+食傷生財的人拿到管理權後，
    會先建規則再帶人，不會走「跟大家打成一片」的路線。
    團隊磨合期她會顯得有點嚴，但這是她建立秩序的方式。
```

你也可以直接丟截圖、聊天記錄、文件，系統會自動提取資訊並更新人格：

```
👤  [貼了一張和小A的LINE聊天截圖]

🤖  從截圖裡提取到 12 條小A的發言，我看到的內容：
    - 「好」、「再說吧」、「你決定就好」
    - 回覆都很短，幾乎不用驚嘆號
    - 你問了三個問題她只回了最後一個

    要把這些寫入她的人格模型嗎？

👤  寫入吧

🤖  已更新 ✓
    語言習慣已同步：短句快節奏、結論導向、不做情緒回應。
    後續對話會更接近她的真實表達方式。
```

## 和普通 AI 聊天有什麼不同

普通 AI 聊天：

```
👤  幫我模擬一個 INTJ 女生

🤖  好的，我來扮演一個 INTJ 女生。我是一個理性、獨立的人……
    （開始背標籤）
```

Bazi Persona Skill：

```
👤  你今天加班到很晚，我說了句辛苦了你只回了「嗯」，是不是不高興了？

🤖  沒有不高興，真的。就是加班到那個點腦子已經轉不動了。
    我這個人本來話就不多，累的時候更不想敷衍你說一堆「謝謝關心」。
    能回你一個字說明我看到了。
    你要是真想表達關心，別說話，明天遞杯咖啡就行。
    我記行動不記話。
```

區別在於：
- **不是「扮演標籤」** — 是八字推導出的底層決策邏輯在驅動回應
- **會隨時間變化** — 即時計算大運/流年/流月/流日/流時的十神、刑沖合會、神煞，同一個人在不同時間的反應真的不一樣
- **越聊越準** — 你補充的真實資訊會持續修正人格模型
- **有深度剖析** — 作弊模式下能從八字和流年角度看到普通聊天看不到的東西

## 快速開始 Quick Start

### Step 1：安裝 Install

在任意 AI Agent 對話框裡貼上這句話：

> 幫我執行 `npx skills add cantian-ai/bazi-persona-skill --all` 安裝八字人格技能

或者你自己在終端執行：

```bash
npx skills add cantian-ai/bazi-persona-skill --all
```

`--all` 會自動安裝到所有支援的 Agent 平台（Claude Code、OpenClaw、Cursor、Windsurf 等 45+ 平台）。

### Step 2：建立第一個人格 Create

回到對話框，直接說：

```text
幫我建立八字人格：小A，女，96年8月12日下午3點半，上海人，我同事
```

AI 會自動排盤、生成人格預覽、進入對話模式。

### Step 3：開始使用 Use

建立完成後，你可以直接和人格聊天：

```text
你最近工作忙嗎？
```

想深度分析，說一句：

```text
打開作弊模式
```

想建立更多人格，隨時說：

```text
再幫我建立一個：小B，男，91年3月12日中午，廣州，朋友
```

### 其他安裝方式

```bash
# 全域安裝 CLI（不依賴 Agent 平台）
npm install -g bazi-persona-skill
bazi --action help
```

## 指令速查 Commands

在 Claude Code / OpenClaw 中使用 `/bazi-persona` 入口，或者直接說人話：

| 你想做什麼 | 斜線指令 | 自然語言 |
|---|---|---|
| 建立人格 | `/bazi-persona create` | 「幫我建立八字人格：小A，女，96年…」 |
| 查看所有人格 | `/bazi-persona list` | 「我有哪些人格？」 |
| 進入對話 | `/bazi-persona {id}` | 「我要跟小A聊天」 |
| 補充資訊 | `/bazi-persona update {id}` | 「小A最近升職了，幫我更新」 |
| 作弊模式 | `/bazi-persona cheatsheet {id}` | 「打開作弊模式」 |
| 時運查詢 | `/bazi-persona flow {id}` | 「小A最近運勢怎樣？」 |
| 合盤分析 | `/bazi-persona compat {a} {b}` | 「小A和小B合盤」 |
| 萬年曆 | `/bazi-persona calendar` | 「今天黃曆怎麼樣？」 |
| 同步 Agent | `/bazi-persona agent enable` | 「把人格同步到 Claude Code」 |
| 幫助 | `/bazi-persona help` | 「有哪些指令？」 |

支援中英雙語，預設跟隨你的輸入語言，也可用 `--lang zh` / `--lang en` 切換。

## 平台整合 Agent Integration

建立好的人格可以同步為 Agent 檔案，之後不用每次都進 Skill，直接在平台裡點名就能開始對話。

### 1. 同步人格到平台

在對話裡說一句：

```text
把我的人格同步到 Claude Code
```

或用指令：

```text
/bazi-persona agent enable
```

系統會自動把所有已建立的人格寫入 Agent 目錄：

| 平台 | Agent 目錄 |
|---|---|
| Claude Code | `~/.claude/agents/bazi-persona/` |
| OpenClaw | `~/.openclaw/agents/bazi-persona/` |

每個人格生成一個獨立 Agent 檔案，外加一個路由檔案自動分發。

### 2. 同步後怎麼用

同步完成後，開啟一個新對話，直接說人名就行：

```
👤  小A

🤖  我在。怎麼了？
```

```
👤  切換到小B

🤖  來了來了，有什麼事？
```

不需要再執行安裝或 `/bazi-persona` 指令，Agent 檔案會讓平台自動識別並載入對應人格。

### 3. 保持同步

每次你建立新人格或更新了已有人格，重新同步一次就行：

```text
幫我重新同步人格到 Agent
```

或刪除所有已同步的 Agent：

```text
/bazi-persona agent remove
```
