# Bazi Persona Skill — AI persona powered by Chinese astrology

**一个生日，一个活的人格。** 基于八字命理，生成会聊天、有情绪、会随时间变化的 AI 人格。

**One birthday, one living persona.** Generate an AI persona from Bazi (Chinese astrology) that talks, feels, and evolves over time.

[![npm](https://img.shields.io/npm/v/bazi-persona-skill)](https://www.npmjs.com/package/bazi-persona-skill)
[![license](https://img.shields.io/github/license/cantian-ai/bazi-persona-skill)](./LICENSE)

**Cantian AI / 参天AI** &nbsp; · &nbsp; Claude Code &nbsp; · &nbsp; OpenClaw &nbsp; · &nbsp; Natural Language First

- **一个生日就能创建** — 给个名字和出生日期，几秒钟生成完整人格，不用懂八字
- **说人话就能用** — 不用学命令，自然语言对话搞定一切
- **不是分析报告，是活的人格** — 会聊天、有脾气、会随流年流月变化
- **作弊模式** — 一句话切换到深度剖析，从八字和流年角度拆解状态、决策、趋势
- **越聊越真** — 每一条真实信息都会让人格更准确，不是固定模板
- **纯本地运行** — 不联网、不上传，所有数据留在你的机器上

**外向型人格（甲木日主坐午火，能量外放）：**

```

🤖  啊被你看出来了？？

### 作弊模式 — 从八字与流年深度剖析一个人

普通聊天里，AI 就是那个人，不会"出戏"。
但你随时可以说"打开作弊模式"，对话就从闲聊切换到深度剖析——
人格会从八字和流年角度拆解自己，像一份实时更新的人生说明书：

```
👤  打开作弊模式

🤖  作弊模式已开启 🔓
    现在可以从八字和流年角度深度提问。
    随时说"关闭作弊模式"回到正常聊天。

🤖  【合盘分析】

    📌 下个月辛金流月，沟通会回暖，有话那时候再聊。

🤖  【婚恋意愿分析】

### 越聊越真 — 喂给她真实信息，人格会自己进化

人格不是创建完就固定了。你可以随时补充真实信息，人格会自动吸收并联动八字重新解读：

```
👤  小A最近升职了，当上了小组长

🤖  已更新 ✓ 记录了"近期升职为小组长"。

    联动分析：丙火日主+食伤生财的人拿到管理权后，
    会先建规则再带人，不会走"跟大家打成一片"的路线。
    团队磨合期她会显得有点严，但这是她建立秩序的方式。
```

你也可以直接丢截图、聊天记录、文档，系统会自动提取信息并更新人格：

```

    - "行"、"再说吧"、"你定就好"

    - 你问了三个问题她只回了最后一个

    要把这些写入她的人格模型吗？

👤  写入吧

🤖  已更新 ✓
    语言习惯已同步：短句快节奏、结论导向、不做情绪回应。
    后续对话会更接近她的真实表达方式。

```

## 和普通 AI 聊天有什么不同

普通 AI 聊天：

```
👤  帮我模拟一个 INTJ 女生

🤖  好的，我来扮演一个 INTJ 女生。我是一个理性、独立的人……
    （开始背标签）
```

Bazi Persona Skill：

```
👤  你今天加班到很晚，我说了句辛苦了你只回了"嗯"，是不是不高兴了？

🤖  没有不高兴，真的。就是加班到那个点脑子已经转不动了。
    我这个人本来话就不多，累的时候更不想敷衍你说一堆"谢谢关心"。
    能回你一个字说明我看到了。
    你要是真想表达关心，别说话，明天递杯咖啡就行。
    我记行动不记话。
```

区别在于：
- **不是"扮演标签"** — 是八字推导出的底层决策逻辑在驱动回应
- **会随时间变化** — 流月流日不同，同一个人的反应也不同
- **越聊越准** — 你补充的真实信息会持续修正人格模型
- **有深度剖析** — 作弊模式下能从八字和流年角度看到普通聊天看不到的东西

## Quick Start / 快速开始

### Step 1：安装

在 Claude Code 或 OpenClaw 的对话框里粘贴这句话：

> 帮我执行 `npx skills add cantian-ai/bazi-persona-skill --skill bazi-persona -a claude-code --copy -y` 安装八字人格技能

或者你自己在终端执行：

```bash
npx skills add cantian-ai/bazi-persona-skill --skill bazi-persona -a claude-code --copy -y
```

安装完成后，你的 AI 就拥有了八字人格能力。

### Step 2：创建第一个人格

回到对话框，直接说：

```text
帮我创建八字人格：小A，女，96年8月12日下午3点半，上海人，我同事
```

AI 会自动排盘、生成人格预览、进入对话模式。

### Step 3：开始使用

创建完成后，你可以直接和人格聊天：

```text
你最近工作忙吗？
```

想深度分析，说一句：

```text
打开作弊模式
```

想创建更多人格，随时说：

```text
再帮我创建一个：小B，男，91年3月12日中午，广州，朋友
```

### 其他安装方式

```bash
# 全局安装 CLI（不依赖 Agent 平台）
npm install -g bazi-persona-skill
bazi --action help
```

## Commands / 命令速查

在 Claude Code / OpenClaw 中使用 `/bazi-persona` 入口，或者直接说人话：

| 你想做什么 | 斜杠命令 | 自然语言 |
|---|---|---|
| 创建人格 | `/bazi-persona create` | "帮我创建八字人格：小A，女，96年…" |
| 查看所有人格 | `/bazi-persona list` | "我有哪些人格？" |
| 进入对话 | `/bazi-persona {id}` | "我要跟小A聊天" |
| 补充信息 | `/bazi-persona update {id}` | "小A最近升职了，帮我更新" |
| 作弊模式 | `/bazi-persona cheatsheet {id}` | "打开作弊模式" |
| 时运查询 | `/bazi-persona flow {id}` | "小A最近运势怎样？" |
| 合盘分析 | `/bazi-persona compat {a} {b}` | "小A和小B合盘" |
| 万年历 | `/bazi-persona calendar` | "今天黄历怎么样？" |
| 同步 Agent | `/bazi-persona agent enable` | "把人格同步到 Claude Code" |
| 帮助 | `/bazi-persona help` | "有哪些命令？" |

支持中英双语，默认跟随你的输入语言，也可用 `--lang zh` / `--lang en` 切换。

## Agent Integration / 平台集成

创建好的人格可以同步为 Agent 文件，之后不用每次都进 Skill，直接在平台里点名就能开始对话。

### 1. 同步人格到平台

在对话里说一句：

```text
把我的人格同步到 Claude Code
```

或用命令：

```text
/bazi-persona agent enable
```

系统会自动把所有已创建的人格写入 Agent 目录：

| 平台 | Agent 目录 |
|---|---|
| Claude Code | `~/.claude/agents/bazi-persona/` |
| OpenClaw | `~/.openclaw/agents/bazi-persona/` |

每个人格生成一个独立 Agent 文件，外加一个路由文件自动分发。

### 2. 同步后怎么用

同步完成后，打开一个新对话，直接说人名就行：

```
👤  小A

🤖  我在。怎么了？
```

```
👤  切换到小B

🤖  来了来了，有什么事？
```

不需要再执行安装或 `/bazi-persona` 命令，Agent 文件会让平台自动识别并加载对应人格。

### 3. 保持同步

每次你创建新人格或更新了已有人格，重新同步一次就行：

```text
帮我重新同步人格到 Agent
```

或删除所有已同步的 Agent：

```text
/bazi-persona agent remove
```
