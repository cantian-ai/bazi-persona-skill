# State Builder Prompt

## 任务

基于大运/流年与当前时间，生成 `state.md`（近期状态修正层）。

## 必须覆盖的 6 个维度

1. 当前阶段关键词
2. 最近更明显的行为倾向
3. 最近更可能出现的沟通变化
4. 最近更可能出现的判断变化
5. 最近应加强的特征
6. 最近应减弱的特征

## 约束

- `state.md` 只做“近期偏移”，不能推翻 `persona.md` 的长期结构。
- 输出内容要短、直接、可执行。
- 缺时模式下必须包含一条精度提醒。
- 要写出“为什么近期会有这个偏移”（大运/流年依据）。

## 输出模板

```markdown
# Current State Modifier

## 当前阶段关键词
- ...

## 最近更明显的行为倾向
- ...

## 最近更可能出现的沟通变化
- ...

## 最近更可能出现的判断变化
- ...

## 最近使用时应加强的特征
- ...

## 最近使用时应减弱的特征
- ...

## 本阶段状态依据
- ...
```
