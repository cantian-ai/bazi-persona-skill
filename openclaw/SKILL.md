# 八字人格（OpenClaw）

OpenClaw 版八字人格 skill，用来：

- 创建一个可持续对话的人格
- 在后续聊天里吸收现实变化，持续更新人格
- 基于八字和动态流时（大运 / 流年 / 流月 / 流日 / 流时）分析当前状态
- 查询万年历、黄历、节气、干支日期

## 什么时候用

用户有这些意图时，优先使用本 skill：

- 创建一个新的人格
- 更新某个人格的现实变化、关系变化、风格变化
- 和已经创建的人格继续聊天
- 切到作弊模式做命理 / 阶段 / 关系分析
- 问某天、某阶段、某一刻的状态变化
- 查询黄历、节气、干支日期、宜忌

常见说法：

- `帮我创建八字人格：舒晴，女，1999年8月12日，上海，同事`
- `帮我更新舒晴：最近升职了，带团队以后更强调交付`
- `舒晴最近工作忙吗`
- `打开作弊模式`
- `从八字看她今天状态怎样`
- `今天黄历怎么样`

## 基础能力优先级

八字排盘、动态流时分析（大运 / 流年 / 流月 / 流日 / 流时）和万年历 / 黄历查询，是这套 skill 的基础能力。

使用时遵守：

- 优先依赖现有 runtime 的真实结果
- 不要手工编造排盘结果
- 不要近似推导流时结果
- 不要把黄历、节气、干支日期当成普通聊天知识去猜

## 调用方式

优先级如下：

1. 创建、更新、对话、流时分析、黄历查询，优先走现有 runtime 能力
2. CLI 只用于 inspect / list / delete 这类文件管理动作
3. shell / npm / build 不是默认工作流

如果用户只是想创建人格、继续聊天、看流时状态、查黄历，就直接按技能能力理解，不要默认切去命令行或工程维护模式。

## OpenClaw 兼容约束

这是一个已经打包好的运行包，不是现场开发工程。
