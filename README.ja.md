# 八字ペルソナ Bazi Persona Skill

**誕生日ひとつで、ひとつの生きた人格。**

中国占星術（八字命理）をベースに、会話し、感情を持ち、時間とともに変化するAIペルソナを生成します。

[![npm](https://img.shields.io/npm/v/bazi-persona-skill)](https://www.npmjs.com/package/bazi-persona-skill)
[![license](https://img.shields.io/badge/license-MIT-blue)](./LICENSE)

[简体中文](./README.md) | [繁體中文](./README.zh-TW.md) | [English](./README.en.md) | [한국어](./README.ko.md)

**Cantian AI / 参天AI** &nbsp; · &nbsp; Claude Code &nbsp; · &nbsp; OpenClaw &nbsp; · &nbsp; 45以上のAgentプラットフォーム

- **誕生日だけで作成** — 名前と生年月日を入力するだけ。数秒で完全なペルソナが完成。八字の知識は不要。
- **占いではなく、生きた人格** — 会話し、感情があり、大運/流年/流月/流日/流時に応じて変化する。
- **チートモード** — 一言で深層分析に切替。八字の静的・動的両面から状態・意思決定・トレンドを解読。
- **使うほどリアルに** — 実際の情報を追加するたびにペルソナがより正確に。固定テンプレートではない。
- **自然言語で操作** — コマンドを覚える必要なし。普通に話すだけ。
- **完全ローカル動作** — インターネット不要、アップロードなし。全データはあなたのマシン上に。

## 実際の動作

### 一文でペルソナ作成

```
👤  八字ペルソナを作って：小A、女性、1996年8月12日午後3時半生まれ、上海出身、同僚

🤖  命盤作成完了 ✓

    【ペルソナ概要】
    1. 一言まとめ：表面は穏やかだが芯は強い。考えてから動くタイプ。
    2. 話し方の印象：無駄がないが冷たくもない。気遣いはするが甘やかさない。
    3. 判断基準：持続可能性とリスク・リターン比。
    4. プレッシャー下の変化：ボトムラインと納品を重視、コミュニケーションが簡潔に。
    5. 最近の状態：安定しながら効率化、意識的に交際を絞っている。

    [小A] 会話モードに入りました ✓
    次のメッセージから、私が彼女です。
```

### ペルソナと会話 — 「演じる」のではなく、本当にその人になる

作成後、AIはその人になります。同じ質問でも、八字が違えば全く異なる反応をします：

**内向型ペルソナ（丙火日主、官殺旺、内斂沈着）：**

```
👤  最近元気ない？

🤖  ないよ……ただ最近忙しいだけ。
    どうしたの？
```

**外向型ペルソナ（甲木日主、食傷旺、表現力豊か）：**

```
👤  最近元気ない？

🤖  え、バレた？？
    もう最近まじでイライラ、仕事ぐちゃぐちゃで——
    新しいリーダーがありえないの、会議2時間で中身ゼロ。
    その場で白目むきそうだった。
    お昼空いてる？ご飯行こ、愚痴聞いて。
```

### チートモード — 八字と運勢から深層分析

普通の会話ではAIはその人のまま。「出ない」。
でも「チートモードON」と言えば、すぐに深層分析に切り替わります。

```
👤  チートモードON

🤖  チートモード開始 🔓
    八字と運勢の観点から深い質問ができます。
    「チートモードOFF」でいつでも通常会話に戻れます。
```

```
👤  今日楽しい？

🤖  【今日の状態 · 庚午日】
    正直、楽しくもないし嫌でもない——ソワソワする感じ。

    午火は私の劫財 → 今日は行動力あるけど衝動的になりやすい。
    庚金が天干にある → 誰かに枠組みを作られる。イラッとするけど逆らわない方がいい。
    今日の神煞に桃花 → 社交運はいいけど、災煞も同時に出てる。感情的な時に余計な約束をしやすい。

    💡 私に話があるなら午前中に来て。午後は多分イライラしてる。
```

## クイックスタート

### Step 1：インストール

任意のAI Agentの会話で以下を貼り付け：

```bash
npx skills add cantian-ai/bazi-persona-skill --all
```

`--all` で対応する全Agentプラットフォーム（Claude Code、OpenClaw、Cursor、Windsurf等45以上）に自動インストール。

### Step 2：最初のペルソナを作成

会話に戻って、こう言うだけ：

```text
八字ペルソナを作って：小A、女性、1996年8月12日午後3時半、上海、同僚
```

### Step 3：使い始める

ペルソナと直接会話：

```text
最近仕事忙しい？
```

深層分析するなら：

```text
チートモードON
```

## コマンド一覧

| やりたいこと | コマンド | 自然言語 |
|---|---|---|
| ペルソナ作成 | `/bazi-persona create` | 「八字ペルソナを作って：小A…」 |
| 一覧 | `/bazi-persona list` | 「ペルソナ一覧見せて」 |
| 会話開始 | `/bazi-persona {id}` | 「小Aと話したい」 |
| 情報追加 | `/bazi-persona update {id}` | 「小Aが昇進した、更新して」 |
| チートモード | `/bazi-persona cheatsheet {id}` | 「チートモードON」 |
| 運勢確認 | `/bazi-persona flow {id}` | 「小Aの最近の運勢は？」 |
| 相性分析 | `/bazi-persona compat {a} {b}` | 「小Aと小Bの相性は？」 |
| 暦 | `/bazi-persona calendar` | 「今日の暦は？」 |
| Agent同期 | `/bazi-persona agent enable` | 「ペルソナをClaude Codeに同期」 |
| ヘルプ | `/bazi-persona help` | 「コマンド一覧」 |
