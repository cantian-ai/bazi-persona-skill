# 사주 페르소나 Bazi Persona Skill

**생일 하나로, 살아있는 인격 하나.**

중국 점성술(사주팔자)을 기반으로 대화하고, 감정을 가지며, 시간에 따라 변화하는 AI 페르소나를 생성합니다.

[简体中文](./README.md) | [繁體中文](./README.zh-TW.md) | [English](./README.en.md) | [日本語](./README.ja.md)

**Cantian AI / 참천AI** &nbsp; · &nbsp; Claude Code &nbsp; · &nbsp; OpenClaw &nbsp; · &nbsp; 45+ Agent 플랫폼

- **생일만 있으면 생성** — 이름과 생년월일만 입력하면 몇 초 만에 완전한 페르소나 완성. 사주 지식 불필요.
- **점이 아니라 살아있는 인격** — 대화하고, 감정이 있고, 대운/유년/유월/유일/유시에 따라 변화.
- **치트 모드** — 한마디로 심층 분석 전환. 사주의 정적·동적 양면에서 상태, 의사결정, 트렌드를 해독.
- **쓸수록 진짜가 됨** — 실제 정보를 추가할 때마다 페르소나가 더 정확해짐. 고정 템플릿이 아님.
- **자연어로 사용** — 명령어 암기 불필요. 그냥 말하면 됨.
- **완전 로컬 실행** — 인터넷 불필요, 업로드 없음. 모든 데이터는 내 컴퓨터에.

## 실제 작동 모습

### 한 문장으로 페르소나 생성

```
👤  사주 페르소나 만들어줘: 소A, 여자, 1996년 8월 12일 오후 3시 반, 상하이, 내 동료

🤖  명반 완성 ✓

    【페르소나 요약】
    1. 한줄 요약: 겉으로는 순해 보이지만 소신이 강함. 계산하고 나서 움직이는 타입.
    2. 말하는 느낌: 쓸데없는 말 안 하지만 차갑지도 않음. 배려는 하되 봐주지는 않음.
    3. 결정 기준: 지속가능성과 리스크-리턴 비율.
    4. 압박받을 때: 마지노선과 결과물을 더 강조, 소통이 간결해짐.
    5. 최근 상태: 안정적으로 효율화 중, 의식적으로 소셜을 줄이는 중.

    [소A] 대화 모드 진입 ✓
    다음 메시지부터 제가 그녀입니다.
```

### 페르소나와 대화 — "연기"가 아니라 진짜 그 사람처럼

생성 후 AI는 그 사람이 됩니다. 같은 질문에도 사주가 다르면 완전히 다른 반응:

**내향형 페르소나 (병화 일주, 관살 강, 내성적):**

```
👤  요즘 기분 안 좋아?

🤖  아니야... 그냥 요즘 일이 좀 많아서.
    왜?
```

**외향형 페르소나 (갑목 일주, 식상 강, 표현력 강):**

```
👤  요즘 기분 안 좋아?

🤖  아 들켰어??
    진짜 요즘 짜증나 죽겠어, 회사에서 별일이 다 있어—
    새로 온 팀장이 진짜 말도 안 돼, 회의 2시간 하는데 내용이 없어.
    거기서 눈 뒤집을 뻔했어.
    점심 시간 돼? 나가서 밥 먹으면서 좀 털어야겠어.
```

### 치트 모드 — 사주와 운세로 심층 분석

보통 대화에서는 AI가 그 사람 그대로. "캐릭터 이탈" 없음.
하지만 "치트 모드 켜줘"라고 하면 바로 심층 분석으로 전환됩니다.

```
👤  치트 모드 켜줘

🤖  치트 모드 ON 🔓
    사주와 운세 관점에서 깊은 질문이 가능합니다.
    "치트 모드 꺼줘"로 언제든 일반 대화로 돌아갑니다.
```

```
👤  오늘 기분 좋아?

🤖  【오늘 상태 · 경오일】
    솔직히 좋지도 나쁘지도 않아—좀 들떠있는 느낌.

    오화는 내 겁재 → 오늘 행동력은 좋은데 충동적이기 쉬워.
    경금이 천간에 눌려있어 → 누군가 나한테 틀을 잡으려 할 거야. 짜증나겠지만 부딪치지 마.
    오늘 신살에 도화 → 소셜 에너지는 좋은데 재살도 같이 있어. 감정적일 때 하면 안 되는 약속을 하기 쉬워.

    💡 나한테 할 말 있으면 오전에 와. 오후는 아마 인내심 없을 거야.
```

## 빠른 시작

### Step 1: 설치

AI Agent 대화창에 붙여넣기:

```bash
npx skills add cantian-ai/bazi-persona-skill --all
```

`--all`로 지원하는 모든 Agent 플랫폼(Claude Code, OpenClaw, Cursor, Windsurf 등 45+)에 자동 설치.

### Step 2: 첫 페르소나 생성

대화로 돌아가서 말하기:

```text
사주 페르소나 만들어줘: 소A, 여자, 1996년 8월 12일 오후 3시 반, 상하이, 동료
```

### Step 3: 사용 시작

페르소나와 바로 대화:

```text
요즘 일 많이 바빠?
```

심층 분석하려면:

```text
치트 모드 켜줘
```
